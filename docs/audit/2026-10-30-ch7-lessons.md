## §7.2既存詳細レッスンの節内点検

| 点検対象 | 独立した判定・計算 |
| --- | --- |
| 層流管内の助走 | 円管・一定物性の目安として`L_h≈0.05Re_D D`、`L_t≈0.05Re_DPrD`。発達度の厳密境界ではない旨を説明済み。 |
| 壁の熱境界条件 | 流動・熱的に十分発達した円管層流では`Nu_D≈3.66`（一定壁温）と`Nu_D=48/11≈4.36`（一定壁熱流束）を区別。 |
| 水力助走長 | `0.05×200×0.020=0.20 m`で正しい。 |
| 熱的助走長 | `0.05×200×5×0.020=1.00 m`で正しい。 |
| 熱伝達率 | `h=Nu_D k_f/D=3.66×0.60/0.020=109.8 W/(m²·K)`で正しい。 |
| 適用制限 | 入口から0.5mは熱的助走長1.0m未満、十分発達の値を全長へ無条件に適用できないと明記。 |
| 単位・記号 | `Re`・`Pr`・`Nu`は無次元、`h`はW/(m²·K)。流体`k_f`と固体`k_s`を混同していない。 |
