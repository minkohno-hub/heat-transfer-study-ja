## 2. 分類別指摘リスト

### 誤り

#### R4-8-001（§8.3）Churchill–Chu 式 (8.13a) に原典に無い下限 Ra_L≳10⁴ を付けている
- 対象: レッスン §8.3 の本文ブロック「平均Nuの相関の一例」および equations「層流側のChurchill–Chu形」の meaning（いずれも「主に10⁴≲Ra_L≲10⁹」と記載）。
- 根拠: 原典 p.419 の (8.13a) の推奨条件は **Ra_L ≲ 10⁹ のみで下限はない**。原典 p.420 は加法定数 0.68 について「境界層的振る舞いが崩れる極低 Ra 域を担う」と明記しており、式は低 Ra 側を含む形で提示されている。10⁴ という下限は原典のどこにもない。
- 影響: Ra_L<10⁴ の条件で学習者が (8.13a) を「適用外」と誤判断する。

#### R4-8-002（§8.4）垂直平板の簡略相関 Nū_L=0.59Ra_L^{1/4} の提示範囲 10⁴≲Ra_L≲10⁹ が原典と一致しない
- 対象: レッスン §8.4 の本文ブロック「垂直面の基準モデル」、equations「層流垂直平板の相関例」、および workedExample 第1例（この式で計算）。
- 根拠: 原典第8章に 0.59Ra^{1/4} という相関は存在しない。原典の層流平均相関は Churchill–Chu (8.13a)（p.419）と Squire–Eckert 平均 (8.27) Nu_L=0.678Ra_L^{1/4}[Pr/(0.952+Pr)]^{1/4}（p.425 付近）である。再検算による影響確認: 例題条件（Ra=7.848×10⁶、Pr=0.75）では 0.59 式は Nu=31.23・h=4.06 W/(m²·K) を与えるが、原典 (8.13a) では Nu=28.06・h=3.65 W/(m²·K) で **約+11% の差**がある。さらに 0.59 式は一般文献（McAdams 系）でも通常 10⁴–10⁷ 級の範囲であり、10⁹ までを「特定の層流範囲」として示す根拠が原典・一般形のいずれにもない。
- 影響: §8.3 で学んだ (8.13a) と §8.4 の 0.59 式が同じ垂直平板で併存し、どちらを使うべきか・差の由来が説明されていない。

### 要改善

#### R4-8-003（§8.2／§8.5）膜 Re の定義は明記されているが、遷移閾値が定義とセットで併記されていない箇所がある
- 確認済みの部分: §8.2 は Re_f=4Γ/μ_l、§8.5 本文は Re_c=Γ/μ_l を主定義とし、両定義の4倍関係も §8.5 に明記されている（原典 (8.72) と p.454 脚注に一致）。定義の明記自体は確認対象を満たす。
- 問題の部分: §8.2 の「Re_f≲30程度が一つの参考」と §8.5 workedExample の limitations「液膜Re_f≲30は非波状層流の概算目安」は、4Γ/μ_l 定義での値である。原典の波状開始 Re_c≃7（Γ/μ_l 定義、p.454）を4倍定義へ換算すると **28** であり「≲30」はその丸めとして概ね妥当だが、(i) 換算の由来が示されていない、(ii) 乱流遷移側の換算値 400×4=1600 が章内のどこにも示されていない、(iii) §8.5 workedExample の Re_f=21.9 は本文の主定義では Re_c=21.9/4=5.47（波状開始7未満＝平滑側）に相当するのに、その対応が例題内に書かれていない。
- 影響: 学習者が §8.5 本文の閾値7／400と §8.2・例題の「30」を直接比較して矛盾と読む余地がある。閾値は定義とセットで併記すべきである。

#### R4-8-004（§8.2）界面境界条件の記法「膜表面で u_y=0」が曖昧
- 対象: レッスン §8.2 の本文ブロック「理想的な垂直膜モデル」（「壁でu=0、膜表面でu_y=0」）。
- 根拠: 原典 (8.6b)（p.415）は界面条件を ∂u/∂y|_{y=δ}=0 と明記する。アプリ内でも問題 supp-buoyancy-film-film-zero-vapor-shear-v1 は「壁でu=0、膜表面で∂u/∂y=0」と正しく書いており、レッスン側の u_y 表記（偏導の略記とも速度成分とも読める）と表記が統一されていない。内容の誤りではないが記法の改善余地がある。

#### R4-8-005（§8.5 関連問題）supp-condensation-corrected-latent-v1 の設定 Ja=0.080 が通常域外であることの断りが設問文にない（軽微）
- 対象: 問題 supp-condensation-corrected-latent-v1（h_fg=2.40×10⁶ J/kg、Pr=4.0、Ja=0.080 で h_fg′ を計算）。
- 根拠: 算術と式 (8.61) 自体は正しく、再検算でも 2.51×10⁶ J/kg に一致する（Stage 6 確定分として式・答は正として扱う）。ただし原典 p.446 は「層流凝縮で通常起こる Ja は 0.02 程度が最大」とし、レッスン §8.5 も「Jaは通常0.02程度以下」と述べる。Ja=0.080 はその4倍で、設問文には Pr≥0.6 の条件しかなく、通常域外の仮想設定である旨は解説の末尾に触れるのみである。学習者が 0.080 を典型値と誤認しないよう、設問文側にも一言ある方がよい。

### 欠落候補（原典にある重要事項でアプリに無いもの）

#### R4-8-006（§8.2）原典 §8.2 の中核である支配方程式系の提示が薄い
- 原典: 運動量方程式の立て方 (8.1)–(8.3)（圧力勾配は境界層外の静水圧勾配、自然対流 dp/dx=ρ_∞g／凝縮 dp/dx=ρ_g g）、整理した式 (8.4)（自然対流）・(8.5)（膜状凝縮）はいずれも浮力が「密度差×g」の形でのみ現れること、共通境界条件 (8.6a) と第3条件 (8.6b) の対比（凝縮: 界面せん断ゼロ／自然対流: 境界層外縁で u=0）、運動量式とエネルギー式が連成する点、δ と δt の関係（凝縮では厳密に等しい、自然対流では Pr≲1 で近似的に等しく高 Pr では δ>δt になりうる）。
- アプリ側: §8.2 レッスンは凝縮膜の導出（原典では §8.5 の内容）に特化し、(8.4)(8.5) の形・(8.3) の圧力勾配・自然対流側の外縁条件・δ≈δt の前提は blocks／equations のいずれにも無い。ノート §8.2 も同様。

#### R4-8-007（§8.3）全 Ra 用の Churchill–Chu 式 (8.13b) が無い
- 原典: p.420 の (8.13b) Nu_L={0.825+0.387Ra_L^{1/6}/[1+(0.492/Pr)^{9/16}]^{8/27}}² は全 Ra・全 Pr に使え、Ra_L>10⁹ の乱流側を担う（層流では (8.13a) の方が正確、という使い分けも明記）。
- アプリ側: §8.3 は (8.13a) のみで、Ra_L>10⁹ の場合の式がレッスン・問題のいずれにも無い（問題 supp-natural-geometry-cylinder-range-v1 は円柱について「別相関を確認する」と正しく誘導するが、垂直平板側の受け皿がない）。

#### R4-8-008（§8.3）Squire–Eckert 古典理論と境界層近似の妥当性の注意が無い
- 原典: 積分法による古典解 — δ/x (8.24)、局所 Nu_x (8.26)、平均 Nu_L=0.678Ra_L^{1/4}[Pr/(0.952+Pr)]^{1/4} (8.27)（Churchill–Chu と大 Ra・Pr で1.2%以内）。また節末では低 Gr で熱境界層が厚くなり境界層方程式自体が使えなくなる領域への注意（Fig. 8.5、Gr≃2250／585 の干渉計写真）、および例題8.2 型の「h∝ΔT^{1/4} のため集中容量応答が指数関数でなく [1+(係数)t]^{−4} 型になる」論点がある。

## 指摘リスト

### 要改善

#### R4-9-001（要改善・§9.3 レッスン）λ_d の下付き区別なしに「水・1 atm で約2.72 cm」
- 内容: レッスン §9.3 第4 block は「Taylor不安定性が蒸気ジェットの間隔の尺度 λ_d を（水・1 atm では約2.72 cm）」とする。
- 根拠: 原書 (9.6a)(9.7)（pp.487–488）では 2.72 cm は一次元波の λ_d1 であり、二次元波は λ_d2=√2·λ_d1。ジェット間隔の尺度として使うのは λ_d1 側なので、数値自体は正しい（再検算: 2π√3·√(σ/(g(ρ_f−ρ_g))) = 2.725 cm）が、λ_d とだけ書くと (9.6a) の2種の波長と混同しうる。λ_d1 と明記するのが望ましい。

#### R4-9-002（要改善・§9.4 ノート）総熱流束の単純分割 q″_total ≈ q″_film + q″_radiation
- 内容: `original-notes.json` §9.4 の relation（supp-section-9-4 の解説にも同文）は「総熱流束の近似として q″_total≈q″_film+q″_radiation と分ける場合がある」とする（モデル条件確認の注意書きは付随）。
- 根拠: 原書 §9.4（p.501）は放射の単純加算を明示的に否定し、放射が蒸気膜を厚くして h_boiling を下げるため、円筒では Bromley 補正 h_total = h_boiling + (3/4)h_rad（h_rad < h_boiling、式 (9.31)）を用いる。レッスン §9.4 本体は (9.31) を正しく収録しているので、本体ではなくノート側の表現が単純加算に読める点のみ要改善（軽微）。

## 概念・条件問題（45問）の照合メモ

- §9.1: 遷移域で q 減少、発泡前は自然対流、膜沸騰域で q 再増加、熱流束制御で q_max 超過時に壁温急昇 — いずれも原書 pp.471–476 と一致。

- supp-section-9-1〜9-11（独立学習ノート）と original-notes §9.1–9.11 は、R4-9-002（§9.4 ノートの放射分割表現）を除き原典と矛盾しない。
