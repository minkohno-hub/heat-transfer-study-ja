## 4. 指摘一覧

新規範囲固有の誤りは **0 件**。以下の3件は、いずれも Muse 側の原書照合（docs/FULLREAD_COLLATION.md の FC 系指摘）が既に記録した問題が、新規22節の範囲にも存在すること、およびその影響範囲の確定である。

### M2-001（重大度: 中）— FC-18 の影響範囲の確定（§6.8・§6.9）

- 内容: レッスン §6.8・§6.9 と問題群が、乱流平板相関の Pr 指数を一律 Pr^{1/3} とする形で統一されている。原書 §6.8 には気体 Pr^0.6 (6.112) と非金属液体 Pr^0.43 (6.113) の2形がある（FC-18 参照）。
- 内部整合: 現行形の内部では算術は完全に整合している（例: §6.8 例題 Nū_L=1498.63、§6.9 の補正定数 C≈871.323 と Nū_L=1299.20 はいずれも検算一致）。
- 影響範囲（FC-18 の修正を採用する場合にセットで再計算が必要なもの）: レッスン §6.8 例題、レッスン §6.9 例題、問題 supp-turbulence-turbulent-heat-rate-v1、supp-turbulence-transition-corrected-nu-v1、supp-turbulence-transition-sensitivity-v1。
- 影響を受けないもの（同グループ内で形に依存しない）: supp-turbulence-local-average-ratio-v1（5/4 倍率は Pr 指数の形に依存しない）、supp-turbulence-transition-length-v1（x_c の計算）。

### M2-002（重大度: 中）— FC-23 のレッスン §7.3 本文での再現

- 内容: レッスン §7.3 が「Dittus–Boelter 形 Nu_D≈0.023 Re_D^0.8 Pr^n（加熱 n≈0.4、冷却 n≈0.3）」と提示し、例題の比較値 Nu≈500.918 もこの形で計算されている。原書 (7.39a–c) の帰属は Colburn 0.023 Re^0.8 Pr^{1/3}、Dittus–Boelter 0.0243 Re^0.8 Pr^0.4、McAdams 0.0225 であり、加熱/冷却の指数切替は原書にない（FC-23 参照）。
- 対応: docs/FULLREAD_FIX_DRAFTS.md の FC-23 修正案（系統別の比較値 Colburn 440.0 / Dittus–Boelter 529.2 / McAdams 490.0、本監査でも検算一致）が §7.3 本文・例題にそのまま適用できる。
- なお §7.3 の問題7問は Gnielinski 式系であり、数値・正答とも整合（指摘なし）。

### M2-003（重大度: 低）— FC-32 のレッスン §8.2 本文での再現

- 内容: レッスン §8.2（Nusselt 膜状凝縮の導出）が補正潜熱 h_fg′ に触れず素の h_fg で導出している。原書は凝縮についても h_fg′ による補正を示す（FC-32 参照）。
- 対応: docs/FULLREAD_FIX_DRAFTS.md の FC-32 修正案（§8.2 への短文追加、再計算不要）が適用できる。§8.2 の問題・例題の数値自体は現行形で整合している。

### 参考（指摘ではない）: 式 (9.29) の照合 — アプリ側が正しく、通読ダイジェスト側に転記誤り

- 問題 supp-phase-correlation-latent-correction-v1 の補正潜熱式 (0.968 − 0.163/Pr_v) は、原書式 (9.29) の印刷（書籍 p.501 を PDF 画像で目視確認）と一致する。正答 h_fg*=2.459 MJ/kg も検算一致し、下流の supp-phase-correlation-cylinder-h-v1 の与件 h_fg*=2.45855×10⁶ J/kg・正答 h_b≈2.28×10² W/(m²·K) も整合する。
