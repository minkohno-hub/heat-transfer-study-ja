## 内容と数値の根拠（全て再検算済み）

### §5.1 時間尺度とモデル選択（レッスン §5.1 workedExample）
- 両面対流平板、半厚さ a=0.010 m、k=1.0 W/(m·K)、ρc_p=1.0×10⁶ J/(m³·K)、h=5.0 W/(m²·K)。
- α = 1.0×10⁻⁶ m²/s、内部拡散尺度 a²/α = 100 s、外部尺度 τ_ext = ρc_p·a/h = 2000 s、Bi = ha/k = 0.050、Fo(200 s) = 2.0、t/τ_ext = Bi·Fo = 0.10。集中モデルで T(200 s) = 20 + 80·exp(−0.1) = 92.386993℃（レッスン解答 92.39℃と一致）。
- 図の構成：①平板模式図＋時間の対数軸バー（100 s / 200 s / 2000 s）、②集中応答曲線 Θ=exp(−t/τ_ext)（41点）、③モデル選択の目安。

### §5.4 線図の読み方（レッスン §5.4・§5.5 の照合値）
- 平板 Bi=1・Fo=0.5 の一項近似：λ₁ = 0.860333589、A₁ = 1.119132008、中心 Θ₀ = 0.772955693（81.84℃）、ξ=0.5 の位置比 cos(λ₁/2) = 0.908896205 → Θ = 0.702536497（76.20℃）、平均 Θ̄ = Θ₀·sinλ₁/λ₁ = 0.681069447（74.49℃）、放出顕熱 1 − Θ̄ = 0.318930553（31.9%）。全てレッスン提示値と一致。
- 図の構成：①中心応答 Θ₀(Fo) の Bi=0.05 / 1 / ∞ の3曲線（一項近似）、②位置プロファイル Θ(ξ) = Θ₀cos(λ₁ξ) と平均線、③読み値の組立てバー。線図そのものの転載ではなく、読み方を示す独自図である旨を desc に明記。

### §5.5 一項近似（レッスン §5.5 workedExample、原書 Table 5.1 / §5.5 式 (5.42)）
- λ₁tanλ₁ = Bi（Bi=1）の根：λ₁ = 0.860333589、λ₂ = 3.425618459。A₁ = 4sinλ₁/[2λ₁ + sin(2λ₁)] = 1.119132008（原書の表 Bi=1.00 行と一致、D2 報告の定数とも一致）。
- Θ₀（一項、Fo=0.5）= 0.772955693。級数（15項）との比較：Fo=0.05 で級数 0.999751 に対し一項 1.078（>1 の外挿限界）、Fo=1 では両者は 1e-6 桁まで一致。
- 図の構成：①固有値条件 λtanλ の2分枝と Bi=1 の交点、②級数（15項）と一項近似の中心応答比較、③位置分布と平均。

### §5.7 定常二次元伝導（レッスン §5.7 workedExample、原書 §5.7）
- 正方形、三辺 20℃・上辺 100℃、θ = (T−20)/80。級数 θ = Σ_{n odd} [4/(nπ)] sin(nπx) sinh(nπy)/sinh(nπ)。
- 中心の部分和：n=1 で 0.253716417（40.2973℃）、n=1,3 で 0.249904097（39.9923℃）、n=1,3,5 で 0.250002952（40.00024℃）。対称性による厳密値 1/4（40℃）へ収束。D2 報告の定数（0.253716417 → 0.250002952）と再検算値が全桁一致した。
- 図の構成：①境界条件の模式図、②中心線プロファイル2本（級数101項で計算）、③部分和の収束プロット（縦軸拡大）。

### §5.8 積解（レッスン §5.8 workedExample、原書 §5.8 式 (5.70)–(5.72)）
- 長い正方形柱、半寸法 a=b=0.010 m、各面 h=100、k=1.0、α=10⁻⁶、t=50 s → 両方向とも Bi=1、Fo=0.50。一次元の一項値（中心 0.772955693、平均 0.681069447）を流用。
- 中心 Θ = 0.772955693² = 0.597460504（67.80℃）、平均 Θ̄ = 0.681069447² = 0.463855592（57.11℃）、放出顕熱 Φ = 1 − Θ̄ = 0.536144408（53.6%）。一次元放出割合の単純和 2×0.318930553 = 0.637861106 は誤りで、Φ = Φ₁ + Φ₂(1 − Φ₁)（原書 (5.72c) の形）と一致することも確認。D2 報告の定数（0.597460504 / 0.463855592）と再検算値が全桁一致した。
- 図の構成：①断面模式図、②中心線プロファイル（一方向だけ vs 積解）、③顕熱 Φ の合成バー（単純和を誤りとして明示）。
