# 教材範囲・公開状況の章別台帳（2026-10-28）

この台帳は `data/book.json`、`data/questions.json` を根拠に、アプリの**状態と章別の独立補助講座**を機械的に整理したものです。書籍の訳文や原図を転載していません。原本との逐文照合や専門家校閲の完了を示すものではありません。

## 解釈上のルール

- **公開日本語節本文**：配信用マニフェストにある日本語の本文データ。現在0/76節。独自補助講座は数に含まない。
- **旧PCの記録**：`draft_complete`/`private_only` はファイル実体・精度・公開可能性を保証しない。旧PCにあると記録された46節を独立に回収・確認していない。
- **独立章別講座**：一般的物理法則を独立に説明したアプリ内ガイド。原本の節本文を翻訳したものではない。
- **書籍出典を持つ問題**：書籍の節・ページを引用先として登録した独立作問7問。章別補助問題33問等とは分けて数える。

## 実施上の優先順位

1. **権利と実体の確認**：旧PC下書き44節および非公開保全2節の実体・原本対応・改訂履歴を回収し、公開配信可能な範囲を個別に判断する。存在記録から本文を推測して補完しない。
2. **高リスク箇所の専門確認**：熱伝導境界条件、フィン、過渡伝熱のBi/Fo、対流相関の適用範囲、自然対流のRa、沸騰CHF、放射の形態係数、物質移動の符号と物性を外部専門家が校閲する。
3. **幅と深さの区別**：全章の概念紹介から、節ごとの独自日本語解説・導出・例題・理解度評価へ段階的に拡充する。原本の翻訳・図の再配布とは権利を分離する。
4. **実機検証**：iPhone Safari、Android、支援技術、オフライン保存、長期保存、バックアップ復元を運用端末で再確認する。

更新時には `node scripts/coverage-summary.mjs --json` とGitHub Actionsの公開ビルド検査結果を参照し、推測の単一完成率は報告しません。
