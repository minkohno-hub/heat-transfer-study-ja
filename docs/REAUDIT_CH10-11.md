### R5-10-001 正答選択肢の文面が否定を欠き、自身の解説と矛盾する
- 対象: questions-ch10.json / supp-kirchhoff-spectral-identifiability-v1（選択肢インデックス1＝正答キー）
- 内容: 正答選択肢の文面が「重みが同じなので、帯別特性には独立な測定情報を追加する」となっている。しかし同問の解説（「二測定は同じ全吸収率を与える。線形式の行が比例して、帯内の二つの未知量を分離できない」）およびレッスン10.2 本文（「同じスペクトルを強くするだけでは重みは変わらず、独立な情報は増えない」）と正反対の命題であり、文面どおりでは誤った結論を学習者に与える。正しくは「追加しない／追加されない」趣旨の文面であるべき指摘。正答キーの位置自体（他の3選択肢が明確に誤りであること）は正しく、数値誤りではない。

### R5-10-002 記号 τ の意味がアプリ内で衝突している（透過率 vs 光学的厚さ）
- 対象: glossary-ch10.json / beer-lambert-radiative-law、non-gray-gas、isothermal-radiating-layer-solution（τ を光学的厚さとして使用）と、notes-ch10.json / 10.5 ほか（τ_λ を透過率として使用）
- 内容: ノート10.5 は透過率を τ_λ=exp(−κ_λL) と定義し、これは原典（10.49）τ_λ≡i_λ(L)/i_λ0=e^(−ρκ_λL) とも一致する。一方、用語集 beer-lambert-radiative-law は「I_out=I_in exp(−τ)、τ=∫β_e ds」、non-gray-gas は「τ_λ=κ_λL」、isothermal-radiating-layer-solution は光学的厚さを τ と置く。同じ τ（特に τ_λ）が一方では透過率（0–1 の比）、他方では光学的厚さ（積 κL）を指し、相互参照時に混同を招く。用語集 radiative-optical-depth 自身が「表面透過率τとは区別する」と τ_o を使い分けているだけに、他エントリの不統一が目立つ。各エントリ内部の数式は定義どおり読めば正しいため誤りではなく要改善とする。レッスン10.5 が透過率に書体字 𝒯 を使って回避している流儀への統一が望ましい。
- 原典根拠: 原典は τ_λ を透過率に予約し（10.49、p.585 付近）、積 ρκ_λL は記号を与えず「optical depth」と呼ぶ。
- 再検算: 数値への影響なし（各エントリの例題数値は再検算一致）。

### R5-10-003 用語集 emissivity の formula 欄が放射率の定義式になっていない
- 対象: glossary-ch10.json / emissivity（formula: 「E=εσT⁴」）
- 内容: 放射率は比 ε=E/E_b（同温度の黒体放射発散度に対する自己放出の比）であり、同エントリの detail 本文はその定義を正しく述べている。しかし formula 欄に置かれた E=εσT⁴ は放射発散度 emissive-power エントリの式そのもので、ε の定義式ではない。formula 欄だけを読む学習者には ε の定義が伝わらない。軽微だが定義欄の不整合として要改善。
- 原典根拠: 原典（10.3）（10.4）（pp.545–546）: ε_λ≡e_λ/e_λb、ε はその黒体重み平均。
- 再検算: 数値への影響なし（同エントリの例「E_b=1000 なら自己放出600」は正しい）。

### R5-10-004 原典の吸収係数 κ_λ（質量基準）との記号対応がアプリ内に示されていない
- 対象: lessons-ch10.json / 10.5、notes-ch10.json / 10.5、glossary-ch10.json / radiative-absorption-coefficient ほか κ を使用する全箇所
- 内容: アプリは κ を [m⁻¹] の体積吸収係数として一貫定義しており、内部整合性と計算は正しい。ただし原典では κ_λ は [m²/kg] の質量吸収係数で、式には密度との積 ρκ_λ の形で現れる（(10.47) di_λ=−ρκ_λ i_λ dx、(10.48)–(10.54)）。原典を併読する学習者が κ_λ の単位と式の形の違いに戸惑う可能性があり、「アプリの κ は原典の ρκ_λ に相当する」旨の一文がない。内容の誤りではないため要改善（読み替え注記）。
- 原典根拠: (10.47)–(10.54)、pp.585–588。
- 再検算: アプリ定義での全計算（χ=κL、𝒯=e^(−χ) 等）は再検算一致。
