## FC-23（§7.3）Dittus–Boelter／Colburn／McAdams の係数系譜

### 根拠（原書 §7.3）
- Colburn 式: Nu_D = 0.023 Re_D^0.8 Pr^(1/3)（7.39a）
- Dittus–Boelter（1930）: Nu_D = 0.0243 Re_D^0.8 Pr^0.4（7.39b）
- McAdams: Nu_D = 0.0225 Re_D^0.8 Pr^0.4（7.39c）
- 初期の式の誤差は 0.67 ≤ Pr ≤ 100 で最大 +25%/−40% 程度。冪乗式の根本問題は Re と Pr の指数が実際には独立でないこと。
- 係数 0.023 は Colburn 式のものであり、「加熱 n≈0.4／冷却 n≈0.3」の指数切替は原書の系譜にはない（他教科書の慣例）。

### 修正案

**(a) レッスン §6.8 ブロック「前縁から乱流の局所相関」**（置き換え）

> 平滑・付着・一定主流・等温・一定物性・弱い吹出し等で、前縁から乱流とする近似として、原書は流体で使い分ける2式を挙げる。気体では Nu_x ≈ 0.0296 Re_x^0.8 Pr^0.6、非金属液体では Nu_x ≈ 0.032 Re_x^0.8 Pr^0.43（Pr ≤ 85 で ±15% 程度）である。Pr の指数は 1/3 ではなく流体種で異なる点に注意する（Pr^(1/3) を一律に使う形は他教科書で見られる別系統の式であり、原書の2式とは一致しない）。ここでは概ね Re_x = 5×10⁵〜10⁷ の目安で用いる。前縁極近傍の厳密解を表すものではなく、実際の層流開始領域を省いた理想化である。なお原書の推奨は、底層補正つきの類似式 St = (C_f/2)／[1 + 12.7(Pr^(2/3) − 1)√(C_f/2)] で、等温・等熱流束の両条件に使える。

**(b) レッスン §6.8 ブロック「平均の倍率は層流と違う」**（置き換え）

> この相関では h_x ∝ x^(−1/5) で、0 から L まで積分した平均 h̄_L は末端局所 h_x(L) の 5/4 倍になる。したがって平均は、気体で Nū_L ≈ 0.037 Re_L^0.8 Pr^0.6、非金属液体で Nū_L ≈ 0.040 Re_L^0.8 Pr^0.43 となる（平均の係数 0.037／0.040 は局所係数 0.0296／0.032 の 5/4 倍で、原書の局所式 (6.112)(6.113) を積分した導出値である）。層流の2倍をそのまま使わない。平均熱流は h̄_L W L ΔT で求めるが、前半に層流があれば §6.9 の履歴を含む積分が必要となる。

## FC-36（§9.3）q_max の係数 0.149 と 0.131 の使い分け

### 根拠（原書 §9.3）
- 無限水平平板: Lienhard–Dhir の q_max = 0.149 √ρ_g h_fg [g(ρ_f − ρ_g)σ]^{1/4}（9.11）が原書の推奨。

## FC-32（§8.5・§8.2）膜凝縮式の補正潜熱 h_fg′
