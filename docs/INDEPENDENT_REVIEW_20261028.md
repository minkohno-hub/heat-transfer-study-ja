## 継続改善（第4段階：公開配信物のブラウザー検査）

- GitHub Actionsの独立したジョブで、ビルド済みの公開配信物をPlaywright/Chromiumから操作する回帰検査を追加した。対象にはガイド21項目、用語集の新規リンク、既存の演習・学習記録・バックアップ・表示テーマ・レスポンシブ画面・英語原本PDFのオフライン範囲取得を含む。**単体テスト成功のみで実際のWeb表示を保証しない**ための検査である。
- runnerの`ubuntu-latest`がUbuntu 26.04となった環境で旧版Playwrightの依存導入ができないことを確認し、ブラウザー専用ジョブをPlaywrightがサポートするUbuntu 24.04へ固定した。既存アプリの動作不良とは区別する。
- SPAの画面切替の検査で、DOM更新前に`count()`や計算済みスタイルを評価する競合があった。必要な要素を待ってから確認する方式へ更新した。
- PDFを明示的に保存するCache Storageと、ブラウザー自身のHTTPキャッシュは別の保存領域である。明示的保存を削除した後でもHTTPキャッシュから一時的にPDFを取得できる場合があるため、テストで無条件にHTTP 503を要求するのは正しくない。明示的なCache Storageが空であることを確認し、別キャッシュから返る場合はPDFの先頭署名を検査する。成功する場合も**長期のオフライン保存保証とは扱わない**。
