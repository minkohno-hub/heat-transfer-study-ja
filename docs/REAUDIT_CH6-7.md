## 確定済み事項の回帰確認

- **FC-18（§6.8・§6.9）: 回帰なし（合格）**
- レッスン §6.8 の局所相関は原書どおり気体 Nu_x≈0.0296 Re_x^0.8 Pr^0.6（式6.112、本p.326）／
非金属液体 Nu_x≈0.032 Re_x^0.8 Pr^0.43（式6.113、本p.327）であり、本文ブロックでも
「Pr^(1/3) を一律に使う形は原書の2式と一致しない」と明示されている。
- レッスン §6.9 の補正 C′ は Pr 依存の形（C′=0.037 Re_c^0.8 Pr^0.6 − 0.664 Re_c^(1/2) Pr^(1/3)）で、
例題の再検算でも C′=665.63（Re_c=5×10⁵、Pr=0.70）が再現された。
- 問題側でも、乱流平板式を一律 Pr^(1/3) とする旧形は存在しない。旧形の定数871系
（(0.037 Re_L^0.8 − 871) Pr^(1/3) = 1299.48）は誤答選択肢としてのみ現れ、正解系と区別されている。
- ただし §6.8 の問題カバレッジについては要改善 R3-I-06 を参照。
- **FC-23（§7.3）: 回帰なし（合格）**
- レッスン・ノート・節別問題の系譜は原書と一致：Colburn Nu_D≈0.023 Re_D^0.8 Pr^(1/3)（式7.39a、本p.368）／
Dittus–Boelter Nu_D≈0.0243 Re_D^0.8 Pr^0.4（式7.39b）／ McAdams Nu_D≈0.0225 Re_D^0.8 Pr^0.4（式7.39c）。
- レッスン §7.3 例題の比較値（Colburn 440.0／Dittus–Boelter 529.2／McAdams 490.0、Re_D=10⁵・Pr=7）も再検算で一致。
- 「加熱時 n=0.4／冷却時 n=0.3 の指数切替」を Dittus–Boelter の原典形として提示する箇所は、
レッスン・ノート・全問題のいずれにも存在しない（当該指数は1問の誤答選択肢としてのみ現れ、正しく否定されている）。
- **Reynolds–Colburn アナロジーの等温壁条件: 未明記（要改善 R3-I-03）**

## 要改善

### R3-I-01 §6.2 δ₉₉の係数「5」と原書 4.92 の差（レッスン・ノート・問題）
- 内容: レッスン §6.2 の式・例題、ノート §6.2、問題 `supp-laminar-velocity-thickness-v1`／`supp-section-6-2` が
δ₉₉ ≈ 5x/√Re_x を使用している。
- 根拠: 原書の Blasius 厳密値は δ/x = 4.92/√Re_x（式6.2、本p.286、η=4.92 が u/u∞=0.99 の位置）。
係数5で計算すると例題値は 9.68 mm、原書係数では 9.53 mm で 1.6% ずれる。
- 判定: 各所とも「目安・近似」と明記され与式とは自己整合するため誤りではないが、
係数を 4.92 に置換するか「概算係数5（原書4.92）」の注記が望ましい。

### R3-I-02 §6.5 相関の Pr 範囲の表記（レッスン・問題）
- 内容(a): レッスン §6.5 の局所相関に「Pr≈0.6〜50」と上限が付されている。
根拠: 原書 式6.58（本p.306）は Pr ≧ 0.6 のみで、上限50は原書に無い。
- 内容(b): 問題 `supp-applied-6-5-v1`／`supp-laminar-plate-local-average-v1` では
式6.58／6.68 の適用範囲 Pr ≧ 0.6 が明記されていない（使用値 Pr=1.0 等は範囲内で結果は正しい）。
- 判定: いずれも数値・正解は正しい。範囲表記を原書に合わせることが望ましい。

### R3-I-03 §6.6 Reynolds–Colburn アナロジーの「等温壁でのみ成立」が明記されていない（レッスン・ノート・問題）
- 内容: 問題側は §6.6 の全8件（本線7＋節別1）のいずれにも等温壁条件の明記がなく、
解説は「熱境界の対応を確認する」等の一般論に留まる。レッスン §6.6 は Pr=1 の Reynolds 類推について
「ゼロ圧力勾配の等温平板等」と述べるものの、Colburn 形については定熱流束壁で成立しない旨の明記がない。
ノート §6.6 の limits も一般論のみ。
- 根拠: 原書 式6.77（本p.313）は等温壁の 式6.58 から導出され、定熱流束壁では 式6.78（本p.313–314）の
とおり 0.4587 ≠ 0.332 で成立しない。圧力勾配・液体金属でも崩れることが同頁に明示されている。
なお乱流形（式6.111）が等温・等熱流束の双方に使えるのは §6.8 側の性質で、§6.6 の層流形とは区別が必要。
- 判定: 数値・正解に誤りはないが、確定済み確認事項である適用条件の明記が不足している。
少なくとも問題1件（analogy-scope 相当）とレッスン §6.6 の Colburn 段落への1文追加が望ましい。

### R3-I-04 §6.7 乱流摩擦・層厚の 1/5 乗形は原書に無い（レッスン）
- 内容: レッスン §6.7 の式「C_f,x ≈ 0.0592 Re_x^(−1/5)、δ ≈ 0.37x Re_x^(−1/5)」は原書第6章に存在しない
（他教科書系の流儀）。出典の区別なく原書ベースのレッスン内に置かれている。
- 根拠: 原書 §6.7 の提示は積分法の δ/x = 0.16 Re_x^(−1/7)、C_f(x) = 0.027 Re_x^(−1/7) と
White の式 C_f(x) = 0.455/[ln(0.06 Re_x)]²（式6.102、いずれも本p.322）。
- 判定: 値自体は標準的な近似で誤りではないが、原書の式への置換または出典区別の注記が望ましい。

### R3-I-05 §6.7 対数則の定数 B=5 と原書 B ≊ 5.5 の差（レッスン）
- 内容: レッスン §6.7 は κ=0.41・B=5 を使用し（式一覧では「B≈5を例示」）、例題も B=5 で計算している
（y⁺=105.4 で u⁺=16.36、ū=5.17 m/s）。
- 根拠: 原書 式6.101（本p.322）は κ=0.41、B ≊ 5.5。原書は §6.8 の導出（本p.325）でも B=5.5 を代入して
式6.111 に至る。B=5.5 で例題を再計算すると u⁺=16.86、ū=5.33 m/s となり、レッスン値と約3.0%ずれる。
- 判定: κ は原書と一致。B=5 は他流儀（κ=0.40 と組の 5.0 等）に見られる値で、「例示」と断りもあるため
誤りとまでは言えないが、原書ベースのレッスンとしては B=5.5 への統一か流儀差の注記が望ましい。

### R3-I-06 §6.8 問題カバレッジ：式6.112／6.113 が §6.8 の問題に登場しない（問題）

### R3-I-08 §7.1・§7.2 助走長の係数 0.05 と原書係数の差（レッスン・問題）

`supp-batch2-thermal-entry-length-v1`／`supp-batch2-pipe-entry-judgment-v1`／
`supp-internal-flow-entrance-state-v1` が、水力学的・熱的の双方に係数 0.05 を使用している。
- 根拠: 原書の水力学的入口長さは xe/D ≃ 0.03 Re_D（式7.12、本p.357。壁面せん断が発達値の5%以内という基準。

熱的入口長さは xet/D ≃ 0.034 Re_D Pr（壁温一定）／0.043 Re_D Pr（熱流束一定）（式7.24、本p.361）で、

- 判定: 問題文は係数を「目安」として明示し算術は与件どおり正しいこと、式7.24 脚注の同時発達の場合の
係数範囲 0.028–0.053 に 0.05 が含まれること、助走域かどうかの定性的結論は原書係数でも不変であることから、
正解の誤りではない。出典・基準の注記が望ましい。

### R3-I-12 §7.5 正方形ダクトの f_D·Re = 56.91 は原書に記載がない（レッスン・問題）【図解パッケージ D4 申し送り事項】
- 内容: レッスン §7.5 の式「正方形: f_D Re ≈ 56.91」と、問題 `supp-geometry-correlation-square-pressure-v1`
