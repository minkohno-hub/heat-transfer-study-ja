# 教材処理と実装の進捗

## 調査記録

- 対象PDF `AHTTv600.pdf` を実行環境から参照できた。pypdfで読めるテキストとしおりを確認した。
- PDFは810ページ。PDFメタデータは第6版、著者 John H. Lienhard IV、作成日2024年。
- 章・節はPDFのしおりに基づいて `data/book.json` に記録した。PDF上の開始ページはしおりのリンク先。書籍ページは本文の通し番号との対応を記録する。
- 権利情報はPDFページ4から確認し、利用条件を `LICENSE-BOOK.md` に転記した。

第1章1.1・1.2節の本文データは、`data/sections/` 内で言語・節ごとに分割し、`data/content-manifest.json` から読み込む。本文言語の初期値は日本語で、読書画面の切り替え設定はブラウザー内に保存される。英語原文もこの2節のみであり、未収録節の英語閲覧には対応していない。

第1章1.2節には式（1.1）〜（1.7）、脚注2、書籍図1.1・1.2を収録した。図画像は原本PDFから抽出し、代替説明と書籍ページ・PDFページを付けた。書籍図1.3は書籍p.10／PDF p.24にあることを確認したが、節1.3本文は未着手。

アプリの表示は翻訳済み節に限定し、未着手の範囲は目次上でも未着手と示す。全訳済みとは表示しない。

## 問題

初期問題は第1章1.1・1.2節の本文から作成したものと、基本的な熱伝導式を説明する「補足説明」に基づくものを区別する。出典、難易度、前提、正答、各誤答の解説、作成・確認状態を各問題に保存する。問題には書籍図1.1を使ったものと、「アプリ作成の図」を使う補足問題がある。すべて専門家校閲待ち。
