# 2026-10-28：用語・演習中ミニ辞典・シミュレーター図解の追加実装と検証記録

## 差分と公開範囲
- **用語集：42→109語（67語追加）**。熱伝導、対流、熱放射、相変化・物性、熱交換器、数学・解析、SI単位・記号を網羅する独立した補足定義を追加。英語名、同義語・表記揺れ、短い定義、初心者向け説明、より詳しい解説、単位、関連式、周辺概念、適用可能な学習ガイドを分離管理。既存42語のID、出典と関連問題リンクを維持し、うち31語に単位・式・関連用語を補充。
- 独立作成の解説には **「補足説明」／「校閲前」** のラベルを維持。原本PDFの掲載許可を日本語全文訳、別出版社、図版再配布等の許諾へ拡大解釈しない。
- **問題文、選択肢、段階ヒント、回答後解説、誤答理由、初心者向け注意、解法手順** から用語ミニ辞典を開ける。**独立日本語節別ノート、独立日本語発展講義、収録済み読書本文（一部の将来的機能）** にも展開。英語原本PDFの内部テキストには、アプリのミニ辞典は自動付加しない。
- 最長一致と少数語強調上限、一般的な一文字単位の除外、HTMLエスケープで誤リンクと読みにくさを抑制。英語名と登録された表記揺れも索引に含める。タップ時は現在の問題を保ち、閉じる/Escape/キーボード/詳細用語集へ対応。問題回答の状態は語を開いても変更しない。
- **計5モデル**に、入力温度・幾何・符号規約と連動するアプリ独自SVG模式図を追加：平板伝導（厚さと両面）、対流（表面・流体・境界層）、熱放射（絶対温度・放射率・囲い）、直列熱抵抗（二層の厚さ）、非定常冷却（温度一様近似・Bi）。温度の逆転、ゼロ流束（例：放射率0）でも矢印を誤表示しないよう、計算した熱流の符号に連動。色以外のラベル・矢印・SVGのtitle/desc・模式図である注記を付与。表示は横スクロールでき、画面を狭くしても文言の読み取りを優先。
- データ保存・問題の正解判定、旧PCにある未移行教材、許可済み原本PDFを含む学習記録の出力形式、他リポジトリの公開範囲は変更しない。新しいデータは `data/glossary.json` に分離し、描画は `term-links.mjs`、物理図は `sim-diagrams.mjs` に分離。公開ビルドのallowlistへ両モジュールを明示追加。
