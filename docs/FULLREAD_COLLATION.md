### 要修正（優先度順）

1. **FC-23（§7.3）Dittus–Boelter と Colburn の係数系譜の混同** — アプリは「Dittus–Boelter = 0.023 Re^0.8 Pr^n（加熱 n≈0.4／冷却 n≈0.3）」と提示するが、原書の系譜は Colburn 式が 0.023 Re^0.8 Pr^(1/3)（7.39a）、Dittus–Boelter（1930）は 0.0243 Re^0.8 Pr^0.4（7.39b）、McAdams は 0.0225 Re^0.8 Pr^0.4（7.39c）であり、加熱／冷却の指数切替は原書にない。数値差は小さいが、本書準拠を掲げる以上、帰属と形は原書に合わせるべき。
2. **FC-18（§6.8）乱流平板の簡便冪乗式の指数** — アプリは局所 0.0296 Re^0.8 Pr^(1/3)／平均 0.037 Re^0.8 Pr^(1/3) のみを提示。原書の冪乗式は気体 0.0296 Re^0.8 Pr^0.6（6.112）と非金属液体 0.032 Re^0.8 Pr^0.43（6.113）の2本であり、Pr=7 級の液体ではアプリ式が2割以上低くなる。原書推奨の Martinelli 型類似式（6.111）も未収録。§6.9 の遷移平均の問題（supp-turbulence-transition-corrected-nu-v1）も同じ Pr^(1/3) 形を使っている。
3. **FC-36（§9.3）q_max の説明用係数** — アプリは大きな水平面の説明用に C≈0.13 を提示するが、これは原書の Zuber–Kutateladze 側の値 0.131 に一致し、同配置に対する原書の推奨値 Lienhard–Dhir 0.149（9.11）ではない（比 1.14）。式の形 q″≈C h_fg √ρ_v [σg(ρ_l−ρ_v)]^(1/4) 自体は原書と一致（原文テキストの例題 9.5 の数値代入 (0.597)^(1/2) で ρ_g^(1/2) 形を確認）。係数の由来と使い分けを明記すべき。
4. **FC-32（§8.5）膜凝縮式の潜熱補正** — アプリの垂直板式は係数 0.943 が原書（8.62b）の 0.9428 と一致する一方、原書が Π4 の中に入れる補正潜熱 h_fg' でなく素の h_fg を使い、Ja 補正への言及がない。原書自身「通常条件では実質無視できる」とする範囲の話だが、式の形としては原書と異なる。h_fg' の一文追加で足りる軽微な相違。

- 推奨: なし。

### 第3章

#### FC-08 LMTD の限界と F 補正（原書 §3.1–3.2）
- 原書: LMTD は単路の並流・向流に限られ、U 一定が前提。U の位置依存は F 補正では救えない本質的限界。F を使うときの LMTD は向流相当で計算する。ΔT_a・ΔT_b は「その端における両流体の温度差」。平衡向流では (3.13) が 0/0 になり極限操作が要る。
- アプリ: レッスン §3.2 が導出前提として一定 U を明示し、0/0 の極限処理、端点の定義（「1と2は熱交換器の二端であり流体番号ではない」）、Q̇ = UAFΔT_lm と問題 supp-existing-lmtd-correction-area-v1 を備える。「U も局所流れ等で変わるため一様 U を仮定できるか確認する」との注意もある。ただし、F 適用時の LMTD が向流相当であることの明示、および「U の位置依存は F で救えない」という形での限界の明示は確認できなかった。
- 判定: **原書と整合**（軽微な注記2点つき）
- 推奨: 任意。§3.2 に F の基準（向流相当）の一文を足すと原書の注意に完全一致する。

#### FC-11 フィンの成立条件 Bifin ≪ 1 と h 一様仮定の限界（原書 §4.5）
- 原書: Bifin ≡ h(A/P)/k ≪ 1（4.27）は「フィン」と呼べる条件そのもの。h 一様の仮定は沸騰・凝縮・一部の自然対流では深刻な誤差源になる。

- 判定: **アプリ側に該当記述なし**（近接する注意・問題はある）
- 推奨: §4.5 に Bifin = h(A/P)/k ≪ 1 の一文と、沸騰・凝縮では h 一様が崩れる旨を足すことを推奨。

- アプリ: レッスン §9.3 は q″_CHF ≈ C h_fg √ρ_v [σg(ρ_l−ρ_v)]^{1/4} の形（原書と同形であることは原文テキストの例題 9.5 の代入 (0.597)^{1/2} = √ρ_g でも確認）を使い、「大きな水平面の説明用には C ≈ 0.13 を置けるが、係数は普遍的な安全定数ではない」とする。0.13 は原書の Zuber–Kutateladze 側 0.131 に一致し、同じ「大きな水平面」に対する原書の推奨 0.149 ではない。0.149／0.131 の区別、Taylor／Helmholtz の2段機構、有限寸法の L′ 補正は収録されていない。アプリが C を条件依存の説明用と明示しているため「誤った断定」ではないが、学習者が大きな平板の q_max を計算すると原書比で約13%低い値になる。
- 判定: **原書と食い違い（要修正・係数の由来の明記）**
- 推奨: §9.3 の説明用係数を原書の 0.149（無限平板）に改め、0.131 は Zuber–Kutateladze 式の値として由来つきで併記すること。あわせて λ_d（水・1 atm で 2.72 cm）のスケール感を一文追加すると原書 §9.3 の骨格が伝わる。

#### FC-37 Rohsenow 相関の精度限界と重力警告（原書 §9.2・§9.7）
- 原書: Rohsenow 相関 (9.4) は水のデータでも熱流束の誤差が典型的に100%、ΔT の誤差は約25%（著者自身の明記）。実務の本題は q_max を超えないこと。また Rohsenow 式の g^{1/2} 依存は地球重力以外へ適用してはならず、核沸騰 h の実測の重力依存は g^{1/8} 程度と弱い。
- アプリ: Rohsenow のプール沸騰相関そのものが収録されていない（§9.7・§9.8 の Bergles–Rohsenow 重ね合わせ式のみ）。したがって精度限界・重力警告も存在しない。なお §9.7 レッスンと問題 supp-system-small-gravity-limit-v1 には「g のべき乗則を微小重力へ無条件に外挿しない」という一般警告があり、方向性は原書と一致する。
- 判定: **アプリ側に該当記述なし**
- 推奨: 統合時の追加候補（相関 (9.4) と精度の自己申告は、沸騰の実務感覚として教育的価値が高い）。

#### FC-38 膜沸騰への放射の加算（原書 §9.4、式 (9.31)）

- アプリ: 問題 supp-phase-correlation-radiation-coupling-v1 が h_total ≈ h_b + (3/4)h_r（h_r < h_b の条件つき）を正確に計算させ、誤答理由に「膜流動への放射の影響を落とし、単純に全量を加えた」を置く。レッスン §9.4 の落とし穴も「放射と蒸気層伝導の独立値を、界面連成を考えず単純加算して保証値にしない」とする。

- 推奨: なし。

#### FC-39 Berenson の q_min は下限値（原書 §9.5、式 (9.34)）

#### FC-40 沸騰曲線の制御方式依存（原書 §9.1・§9.6）

- アプリ: レッスン §9.5 が「温度制御と熱入力制御を区別する」ブロックで、壁温制御では曲線上の点を観測できる一方、熱入力一定の系では「曲線のある点を描けることと、その点に安定してとどまれることは別」と明記。加熱経路と冷却経路が一致しない履歴依存、§9.6 の負の傾きの不安定性の説明もある。
