# 熱移動を学ぶ

公開URL：[熱移動を学ぶ](https://minkohno-hub.github.io/heat-transfer-study-ja/)。PCやスマートフォンのブラウザーから、ログインや開発環境のインストールなしで利用できます。学習記録は端末内に保存され、端末間で自動同期しません。設定画面からJSONで書き出し・復元できます。

この公開サイトは、開発中の [`codex/quality-audit-local-pack`](https://github.com/minkohno-hub/heat-transfer-study-ja/pull/1) ブランチから、許可ファイルだけを選ぶビルドで配信しています。この `main` ブランチはPagesの手動デプロイ経路と権利保護のための整備中です。アプリ本体の最新コードと開発・テスト手順はPR #1を参照してください。

公開サイトには、アプリ作成の日本語ガイド、補足問題8問、4種類の簡易シミュレーター、学習履歴・復習・検索・設定などがあります。書籍由来の本文・全文翻訳・原図は配信していません。現在公開版で読める書籍本文は **0/76節** であり、書籍全体の完成を意味しません。原本と旧教材データは非公開教材リポジトリで管理します。以前このリポジトリに存在した§1.1・§1.2の本文、図、旧問題は非公開リポジトリにも保全済みですが、過去のGit履歴を書き換えてはいません。

アプリ内の「使い方・学習ガイド」に操作とシミュレーションの理論・単位・前提・例題を載せています。初回読み込み後はガイド、公開問題、シミュレーターと端末内の記録を可能な範囲でオフライン利用できます。iPhone・Android実機、Safari・Firefox、支援技術、外部専門家による教材校閲は未確認です。
