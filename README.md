# 熱移動を学ぶ

熱移動を初めて学ぶ人向けの、日本語を既定にしたオフライン対応学習アプリです。読書画面では、日本語訳と収録済みの英語原文を切り替えられます。現在はローカルで利用する前提の独立したGitリポジトリとして作成しています。書籍の教材データを含むため、許諾範囲を確認せずに公開リポジトリへ送らないでください。

## 起動方法

Python 3 が使える環境で、このフォルダーを開いて次を実行します。

```powershell
python -m http.server 4173
```

ブラウザーで `http://localhost:4173` を開きます。初回読み込み後は教材とアプリの基本機能をオフラインで利用できます。ブラウザーの音声読み上げは端末とブラウザーの機能に依存します。

## 現在の教材範囲

- 書籍: *A Heat Transfer Textbook*, Sixth Edition, Version 6.00 (2024)
- PDF: 810ページ。PDF内のしおりから章・節を取得しました。
- 日本語訳: 第1章1.1節（書籍 pp.3–6、PDF pp.17–20）と1.2節（書籍 pp.6–9、PDF pp.20–23）を収録しています。式、脚注、原本の図1.1・1.2を含みます。専門家校閲は未実施です。
- 英語原文: 第1章1.1・1.2節を収録し、日本語訳と切り替えられます。初期設定は日本語です。英語読み上げと英語本文検索にも対応します。
- 第1章1.3–1.5節、章末問題、参考文献、および他章・付録・索引は目次と進捗台帳に登録済みですが、翻訳は未着手です。
- 12問を収録し、第1章1.1・1.2節に基づく問題と明示した補足問題を分けています。問題の専門家校閲は未実施です。

章・節の見出しとページ情報は `data/book.json`、各節の日本語・英語本文は `data/sections/`、収録ファイル一覧は `data/content-manifest.json` で管理しています。

進捗の詳細は `docs/CONTENT_PROGRESS.md` と `data/book.json` を参照してください。全訳を完了したアプリではありません。

## 保存とプライバシー

学習履歴、しおり、メモ、設定はこのブラウザーのローカルストレージに保存します。外部サービスへ送信しません。学習データは設定画面からJSONで書き出し・取り込みできます。
