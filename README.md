## 開発環境で起動する（一般利用者の操作は不要）

Node.jsが利用できる環境で、アプリのフォルダーを開いて実行します。アプリ本体にパッケージのインストールは不要です。

```powershell
node scripts/serve.mjs
```

表示された `http://127.0.0.1:4173` をブラウザーで開いてください。終了はターミナルで `Ctrl+C` です。`index.html` の直接起動には対応していません。

既存のPython起動方法も使えます。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

別のポートが必要な場合は、Node版で次を実行します。ポートごとに保存先が異なるため、いつもの学習記録を使うときはURLを変えないでください。

```powershell
$env:PORT = '4174'
node scripts/serve.mjs
```

公開URL：[熱移動を学ぶ](https://minkohno-hub.github.io/heat-transfer-study-ja/)。スマートフォンに合わせた画面配置があります。上のサーバーは開発者用です。一般利用者はURLから開き、Node.jsやPython、ターミナル操作を使いません。公開URLの稼働確認は [VERIFICATION.md](docs/VERIFICATION.md) に記録します。

## 実装している機能

- ホーム、読書、問題演習、復習、検索、用語集、分野マップ、シミュレーター、計画、カレンダー、設定、使い方・学習ガイドの12画面。ガイドは17項目、4モデルの式・単位・手計算例を含みます。
- 許可された教材がある環境での日本語・英語切り替え、段落単位の読書位置、本文しおりと編集可能なメモ。公開版では原本PDFを閲覧し、節ごとの読了・節の開始ページへのしおり・自分のメモを記録できます。PDFビューアー内のページ位置はアプリと自動連動しません。問題ブックマークは別管理です。
- 4択回答、自信度、段階ヒント、全選択肢の理由、間違いノート、端末内の問題報告、演習のふり返り。選択肢の表示順は演習ごとに変わり、中断・再開時には維持されます。
- 演習の中断・再開。選んだ答え、自信度、ヒント、回答済み状態を保存し、問題の改訂時は理由を示して誤った再開を防ぎます。
- 履歴・自信度からの復習候補と理由、復習日の提案・変更、5分・10分セット、計画の保存・停止。
- 本文・見出し・用語・問題・解説・メモ・しおり・ブックマークの横断検索。章・分野・種類による絞り込み、抜粋・強調・該当箇所への移動。
- 熱伝導、対流、熱放射、二層平板と両側対流の直列熱抵抗の4モデル。単位・仮定、Kへの換算、入力エラー、段階的な代入、界面温度、条件保存とグラフ比較。
- 読書を含む学習時間の日別記録。前面表示・操作状態を使い、90秒超の無操作とPC休止の空白を除外。同じ問題の反復で分野の理解度が増えない指標。
- ライト・ダーク・端末設定、文字サイズ・行間・本文幅、数字キーとEnter、読み上げ機能。実音声と支援技術での確認は未実施。
- ローカル保存、JSONの書き出し・表示・追加復元・置き換え。形式検査と復元前の控え、保存失敗時の通知。
- 初回取得後の公開ガイド・問題・シミュレーターのオフライン利用。原本PDFは「オフライン保存」を明示的に実行し、画面の保存状態と完了通知を確認してから対応ブラウザーで利用できます。再読み込み時に保存状態を再確認します。約31MBの空き容量が必要です。追加のローカル教材も取得後にキャッシュします。

## 保存とプライバシー

学習データはブラウザーのローカルストレージに保存し、外部へ送信しません。URL・ポート・ブラウザーを変えると別の保存先になります。ブラウザーのデータ削除やプライベートモードの終了に備え、設定からJSONを書き出してください。書き出しには回答時の選択肢の文言が含まれます。書籍の全文は含まれません。

取り込みは形式を確認してから利用者が実行します。壊れた形式や保存不能の場合は既存データを保持します。取り込み前の控えは端末内に保存し、設定画面で内容を確認・書き出し・復元できます。時差のある日時は実際の時刻で比較します。同じ利用者の記録を複数タブで開き、別のタブが先に更新した場合は古いタブからの保存・復元を止めて警告します。古いタブで必要な変更があればJSONを書き出してから再読み込みしてください。同時書き込みを完全に直列化する仕組みではないため、同じ利用者の記録を複数タブで同時編集することは避けてください。設定画面で利用者を追加すると、回答・メモ・しおり・設定と復元前の控えを利用者別に保存します。従来のデータは「既存の記録」に残ります。利用者の切り替えにパスワードはなく、同じブラウザーを使う人はほかの利用者の記録も開けます。機密性が必要な共用端末ではブラウザーの利用者プロファイルも分けてください。自動の端末間同期はありません。

## 教材データの構成

- `book/AHTTv600.pdf`：許諾済みの英語原本。公開ビルドでサイズ・SHA-256を確認します。
- `data/book.json`：章・節・出典ページ・翻訳と確認の状態。
- `data/content-manifest.json`：公開版では空。旧§1.1・§1.2の本文・原図は非公開教材リポジトリの `legacy-app-content/` に保全。
- `data/questions.json`、`data/glossary.json`：公開可能なアプリ作成の補足問題8問・用語。
- `data/drafts/`：許諾された学習用途の翻訳・図・問題の下書き。Git管理対象外。
- `data/local/`、`data/local-content-manifest.json`：このPCの追加教材。Git管理対象外。
- `data/source/pages/`、`data/source/sections/`：PDFのページ別抽出本文と節対応。Git管理対象外。原本は `book/AHTTv600.pdf`。

原本照合記録のある下書きが作業環境にある場合、次で§7.6・§7.7・§8.1–§8.3のローカル教材を組み立てます。現在のクラウドには下書きがないため、この処理は実行できません。

```powershell
node scripts/build-local-pack.mjs
```

追加教材を読み込むときは、原本照合済みの表示と本文ブロックの構造を確認します。空の節や表示できない種類・壊れた表を含む場合は追加教材全体の取り込みを中止し、収録済み本文を表示します。書籍図の画像はアプリ内の教材パスだけを参照し、外部サイトの画像は表示しません。旧PCの教材を移した後は、実物の構造と出典を照合し、ローカル教材用のテストも実行してください。

## 確認する

自動テストはNode.jsのみで実行できます。

```powershell
node --test tests/*.test.mjs
node scripts/audit-content.mjs --check
node scripts/build-public-site.mjs
node tests/browser-distribution.mjs
```

`build-public-site.mjs` は許可したファイルだけを `dist/` へ出力し、原本PDFを含めます。翻訳・抽出本文・原図単体は含めません。`tests/browser-distribution.mjs` はその配信物を確認します。PlaywrightとChromiumが必要です。既存のローカル教材を使う総合確認は `tests/browser.mjs` です。ローカル教材がある環境で、`PLAYWRIGHT_MODULE` にPlaywrightの場所、`BROWSER_EXECUTABLE` にブラウザーの実行ファイルを設定して実行します。確認専用の一時プロファイルを使います。実施結果と未確認範囲は [VERIFICATION.md](docs/VERIFICATION.md) に記録しています。クラウドでの引き継ぎ状態は [CLOUD_HANDOFF.md](docs/CLOUD_HANDOFF.md) を参照してください。
