## 保存とプライバシー

学習データはブラウザーのローカルストレージに保存し、外部へ送信しません。URL・ポート・ブラウザーを変えると別の保存先になります。ブラウザーのデータ削除やプライベートモードの終了に備え、設定からJSONを書き出してください。書き出しには回答時の選択肢の文言が含まれます。書籍の全文は含まれません。

取り込みは形式を確認してから利用者が実行します。壊れた形式や保存不能の場合は既存データを保持します。取り込み前の控えは端末内に保存し、設定画面で内容を確認・書き出し・復元できます。時差のある日時は実際の時刻で比較します。同じ利用者の記録を複数タブで開き、別のタブが先に更新した場合は古いタブからの保存・復元を止めて警告します。古いタブで必要な変更があればJSONを書き出してから再読み込みしてください。同時書き込みを完全に直列化する仕組みではないため、同じ利用者の記録を複数タブで同時編集することは避けてください。設定画面で利用者を追加すると、回答・メモ・しおり・設定と復元前の控えを利用者別に保存します。従来のデータは「既存の記録」に残ります。利用者の切り替えにパスワードはなく、同じブラウザーを使う人はほかの利用者の記録も開けます。機密性が必要な共用端末ではブラウザーの利用者プロファイルも分けてください。自動の端末間同期はありません。


追加教材を読み込むときは、原本照合済みか未照合の下書きかという表示と、本文ブロックの構造を確認します。空の節や表示できない種類・壊れた表を含む場合は追加教材全体の取り込みを中止し、収録済み本文を表示します。書籍図の画像はアプリ内の教材パスだけを参照し、外部サイトの画像は表示しません。旧PCの教材を移した後は、実物の構造と出典を照合し、ローカル教材用のテストも実行してください。

## 確認する

自動テストはNode.jsのみで実行できます。

```powershell
node --test tests/*.test.mjs
node scripts/audit-content.mjs --check
node scripts/build-public-site.mjs
node tests/browser-distribution.mjs
```

`build-public-site.mjs` は許可したファイルだけを `dist/` へ出力し、原本PDFを含めます。翻訳・抽出本文・原図単体は含めません。`tests/browser-distribution.mjs` はその配信物を確認します。既定はPlaywrightとChromiumで、`BROWSER_ENGINE=firefox` では同じオフライン確認を実行します。`BROWSER_ENGINE=webkit` では主要画面・保存・オンラインでのPDF範囲取得を確認します。Playwright WebKitのオフライン再訪は内部エラーで未検証であり、iPhone Safari実機の確認も残ります。既存のローカル教材を使う総合確認は `tests/browser.mjs` です。ローカル教材がある環境で、`PLAYWRIGHT_MODULE` にPlaywrightの場所、`BROWSER_EXECUTABLE` にブラウザーの実行ファイルを設定して実行します。確認専用の一時プロファイルを使います。実施結果と未確認範囲は [VERIFICATION.md](docs/VERIFICATION.md) に記録しています。クラウドでの引き継ぎ状態は [CLOUD_HANDOFF.md](docs/CLOUD_HANDOFF.md) を参照してください。

## 2026-10-28 非定常冷却の独立シミュレーター

集中熱容量近似を5つ目のモデルとして追加。ρVcₚ dT/dt=−hA(T−T∞)、τ=ρVcₚ/(hA)、Bi=h(V/A)/k。初期値から時刻tまでの物体温度・瞬間の放熱率・累積熱量を表示し、手計算式、単位、モデルの仮定、適用性、周囲より低温からの加熱にも対応。Bi≥0.1でも数値が出ることと近似が有効であることは区別し、警告を表示します。時間を横軸とする温度履歴をグラフ化し、保存条件と比較できます。学習用の単純化した解析モデルであり、工業設計の保証値として使用できません。公開サイトでの配信にはCodex PR #1の承認と配信ワークフローが別途必要です。
