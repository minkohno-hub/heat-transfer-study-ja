## 起動する（Windows PowerShell）

Node.jsが利用できる環境で、アプリのフォルダーを開いて実行します。アプリ本体にパッケージのインストールは不要です。

```powershell
node scripts/serve.mjs
```

表示された `http://127.0.0.1:4173` をブラウザーで開いてください。終了はターミナルで `Ctrl+C` です。`index.html` の直接起動には対応していません。

既存のPython起動方法も使えます。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

別のポートが必要な場合は、Node版で次を実行します。ポートごとに保存先が異なるため、いつもの学習記録を使うときはURLを変えないでください。

```powershell
$env:PORT = '4174'
node scripts/serve.mjs
```

スマートフォンに合わせた画面配置があります。上のサーバーはこのPCの中で動作します。スマートフォンへの配信・公開ホスティングは未設定です。

## 保存とプライバシー

学習データはブラウザーのローカルストレージに保存し、外部へ送信しません。URL・ポート・ブラウザーを変えると別の保存先になります。ブラウザーのデータ削除やプライベートモードの終了に備え、設定からJSONを書き出してください。書き出しには回答時の選択肢の文言が含まれます。書籍の全文は含まれません。

取り込みは形式を確認してから利用者が実行します。壊れた形式や保存不能の場合は既存データを保持します。置き換え前の控えは端末内に保存しますが、その控えを画面から取り出す機能は未実装です。

## 教材データの構成

- `data/book.json`：章・節・出典ページ・翻訳と確認の状態。
- `data/sections/`、`data/content-manifest.json`：既存収録本文。
- `data/questions.json`、`data/glossary.json`：既存問題・用語。
- `data/drafts/`：許諾された学習用途の翻訳・図・問題の下書き。Git管理対象外。
- `data/local/`、`data/local-content-manifest.json`：このPCの追加教材。Git管理対象外。

原本照合済みの下書きがこのPCにある場合、次で§7.6・§7.7のローカル教材を組み立てます。公開版だけを取得した環境には下書きがないため、この処理は実行できません。

```powershell
node scripts/build-local-pack.mjs
```

## 確認する

自動テストはNode.jsのみで実行できます。

```powershell
node --test tests/core.test.mjs tests/app.test.mjs tests/content.test.mjs
node scripts/audit-content.mjs --check
```

実ブラウザー確認は `tests/browser.mjs` です。PlaywrightとChrome、§7.6・§7.7のローカル教材が必要です。`PLAYWRIGHT_MODULE` にPlaywrightの場所、`BROWSER_EXECUTABLE` にブラウザーの実行ファイルを設定して `node tests/browser.mjs` を実行します。利用者の学習データには触れない確認専用の一時環境を使います。実施結果と未確認範囲は [VERIFICATION.md](docs/VERIFICATION.md) に記録しています。
